Companion

Your finds, ready for later.

Connect your laptop

Use the same Companion server and Supabase project as your phone. You only need to do this once.

For a server on this laptop, use http://localhost:8080.

Use the public client key from your project settings. Keep secret, service-role, and runner tokens out of this form.

After connecting

Pin Companion in your browser toolbar. Open a post, click Companion, and select Save to Companion. You can also right-click a link to save it.

This browser signs in separately from your phone. Both send links to the same server, and your existing runner picks them up. Phone notifications and duplicate detection are tied to each sign-in.

Installation and usage guide
Only links you choose to save are sent. No page content or browsing history is collected.
